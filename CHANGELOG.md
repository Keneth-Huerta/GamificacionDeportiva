# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [No Publicado]

### Agregado
- Sistema completo de gamificación deportiva
- Soporte para múltiples tipos de deportes (Correr, Natación, Ciclismo, Fútbol, Baloncesto, Volleyball, Gimnasio)
- Sistema de logros con diferentes categorías
- Sistema de desafíos temporales
- Competencias entre usuarios
- Panel de administración para usuarios administradores
- Interfaz gráfica con gráficos estadísticos
- Sistema de niveles y experiencia
- Cálculo automático de calorías quemadas
- Gestión de perfiles de usuario con foto
- Persistencia de datos en MySQL
- Documentación completa (JavaDoc público y privado)

### Características Principales

#### Sistema de Gamificación
- Niveles progresivos basados en experiencia
- Sistema de puntos
- Logros desbloqueables
- Desafíos con límite temporal
- Competencias grupales

#### Gestión de Actividades
- Registro detallado de actividades deportivas
- Seguimiento de duración, distancia y calorías
- Historial completo de actividades
- Estadísticas por tipo de deporte

#### Análisis y Visualización
- Gráficos de progreso
- Estadísticas semanales
- Comparativas entre usuarios
- Dashboard administrativo

#### Interfaz de Usuario
- Pantalla de inicio de sesión
- Pantalla de carga
- Panel principal con navegación intuitiva
- Formulario de edición de perfil
- Visualizaciones gráficas interactivas

### Seguridad
- Sistema de roles (usuario/administrador)
- Gestión segura de contraseñas en base de datos
- Soporte para variables de entorno para credenciales

## Tipos de Cambios

- `Agregado` para nuevas características.
- `Cambiado` para cambios en funcionalidades existentes.
- `Obsoleto` para características que serán removidas en versiones futuras.
- `Removido` para características removidas.
- `Corregido` para corrección de bugs.
- `Seguridad` en caso de vulnerabilidades.

## Versionado

Usamos [SemVer](http://semver.org/) para el versionado:
- MAJOR: Cambios incompatibles en la API
- MINOR: Nuevas funcionalidades compatibles con versiones anteriores
- PATCH: Correcciones de bugs compatibles con versiones anteriores
